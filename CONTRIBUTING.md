# Contributing to Devops

Thanks for your interest in contributing! Here is how you can help:

1. **Report Bugs:** Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md) to report issues.
2. **Submit Pull Requests:** 
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/amazing-feature`).
   - Commit your changes and open a pull request against the `master` branch.
